# vSLAM Quiz

An interactive quiz application to test your knowledge about Visual SLAM (Simultaneous Localization and Mapping).

## About vSLAM

Visual SLAM (vSLAM) is a technology that enables robots and autonomous systems to build a map of an unknown environment while simultaneously tracking their position within that map using visual sensors like cameras.

## Features

- 10 comprehensive questions covering key vSLAM concepts
- Multiple-choice format with immediate feedback
- Detailed explanations for each answer
- Score tracking and performance evaluation
- Interactive command-line interface

## Requirements

- Python 3.6 or higher

## How to Run

1. Make the quiz executable (Unix/Linux/Mac):
   ```bash
   chmod +x quiz.py
   ./quiz.py
   ```

2. Or run with Python directly:
   ```bash
   python3 quiz.py
   ```

## Quiz Topics

The quiz covers various aspects of vSLAM including:
- Basic SLAM concepts and terminology
- Visual sensors and feature detection
- Popular vSLAM algorithms (ORB-SLAM, SIFT)
- Mathematical techniques (Kalman Filters)
- Common challenges in vSLAM
- Loop closure detection
- Localization and mapping fundamentals

## Usage

Once you start the quiz, you'll be presented with multiple-choice questions. Answer each question by typing the letter (A, B, C, or D) corresponding to your choice. You can quit at any time by typing 'Q'.

After completing the quiz, you'll receive:
- Your total score
- Percentage correct
- Performance evaluation
